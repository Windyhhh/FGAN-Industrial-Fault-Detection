================================================================================
基于特征双向生成对抗网络的工业过程故障检测系统
================================================================================

一、项目概述
------------

本项目实现了一个基于FBGAN（Feature-based Bidirectional GAN）的工业过程
故障检测系统，应用于Tennessee Eastman Process数据集。

核心特点：
  ✓ 无监督学习（仅使用正常数据训练）
  ✓ 低误报率（1.30%）
  ✓ 高检出率（16/21个故障达到90%以上）
  ✓ 自适应阈值估计


二、文件说明
------------

核心文件：
  - FBGAN.py              : FBGAN网络模型定义
  - FENETFIL.py           : 特征提取模块
  - config.py             : 配置参数
  - fault_detection1.py   : 故障检测主程序
  - test_all_faults.py    : 批量测试所有故障

数据文件：
  - d00_train.csv         : 正常训练数据（4000样本）
  - d00_test.csv          : 正常测试数据（2000样本）
  - d01_test.csv ~ d21_test.csv : 21种故障测试数据（每种2001样本）

模型文件：
  - models/complete_model.pth : 训练好的FBGAN模型
  - models/scaler.pkl         : 数据标准化器

文档：
  - README.md             : 详细的项目说明文档
  - RESULTS.md            : 实验结果与性能分析
  - 项目说明.txt         : 本文件（快速入门）


三、快速开始
------------

1. 环境要求：
   Python >= 3.8
   torch >= 1.8.0
   numpy, pandas, scikit-learn, scipy

2. 测试单个故障：
   
   步骤1：打开 fault_detection1.py
   步骤2：修改第21行的故障编号
          FAULT_NUMBER = 3  # 改为1-21之间的任意数字
   步骤3：运行
          python fault_detection1.py

3. 测试所有故障：
   
   直接运行：
   python test_all_faults.py
   
   结果将保存在 results/all_faults_test.csv

五、技术亮点
------------

1. 双向生成对抗网络
   - 数据空间 ↔ 特征空间的双向映射
   - 循环一致性约束提高重构质量
   - 多判别器提供多角度异常检测信号

2. 多维度特征提取
   - DPCA统计量（捕捉时序相关性）
   - PCA统计量（捕捉静态特征）
   - 马氏距离（度量多变量偏离）
   - 滑动窗口特征（捕捉变化趋势）
   - 输出13维紧凑特征

3. 自适应阈值估计
   - 基于核密度估计（KDE）
   - 98%置信水平
   - 自动适应数据分布

4. 多维度异常评分
   - 数据重构误差（权重40%）
   - 特征重构误差（权重35%）
   - 特征判别分数（权重15%）
   - 数据判别分数（权重10%）

七、使用建议
------------

1. 测试时注意：
   - 故障编号范围为1-21
   - 故障数据前160个样本为故障引入期，系统会自动跳过
   - 确保数据文件格式正确（CSV，无表头，31列）

2. 参数调整：
   - 如需调整误报率和检出率的平衡，可修改config.py中的confidence_level
   - 提高confidence_level → 降低误报率，但可能降低检出率
   - 降低confidence_level → 提高检出率，但可能增加误报率

3. 查看详细结果：
   - 每次测试后，详细结果保存在 results/fault_XX/ 目录下
   - 包括异常分数分布、检测结果等
